# Security policy

## Reporting a vulnerability

Please do not open a public issue, pull request or discussion for a security
problem.

Use GitHub's private vulnerability reporting: open the **Security** tab of the
affected repository and choose **Report a vulnerability**. If the tab offers no
such option, open an issue that asks for a private contact channel and contains
no details about the problem.

Include what you found, how to reproduce it and which version or commit is
affected. Never include real secrets or personal data.

## What to expect

Reports are acknowledged, assessed and answered by the maintainers of the
affected repository. A confirmed vulnerability is fixed and disclosed in
coordination with the reporter.

## Supported versions

Security fixes go to the latest release, or to the default branch for
repositories without releases.
